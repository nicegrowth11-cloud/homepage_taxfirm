# 세무법인 BHL 강남지점 홈페이지

대표세무사 김인화. 병의원·부동산·창업 세무 안내 홈페이지입니다.

## Vercel 배포
GitHub의 main 브랜치를 Vercel에 연결합니다. Framework Preset: Other. 별도 설치나 빌드 없이 저장소 루트의 index.html, style.css, script.js를 배포합니다. 설정은 vercel.json에 포함되어 있습니다.

## 편집
- index.html: 본문과 링크
- style.css: 디자인과 반응형 스타일
- script.js: 모바일 메뉴

유튜브 영상과 SNS 주소는 제공 후 연결합니다.
